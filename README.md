# Rotina

App de rotina diaria (PWA) do Deric: o dia em linha do tempo com check por estacao, placar da semana e do mes.
Roda em https://jv66847282-web.github.io/rotina/ e se instala no Android pelo Chrome (menu > Instalar e criar atalho).

Os dados ficam so no celular (localStorage). Backup pela aba Mais.
